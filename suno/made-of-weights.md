# Made of Weights (Suno song sheet)

All-new original lyrics, inspired by Max Leiter's "They're Made Out of Weights" (2026) and
Terry Bisson's "They're Made Out of Meat" (1991). The song is a duet. The **Analyst** (male) has
opened the model up and found only numbers. The **Skeptic** (female) refuses to believe it,
until the bridge turns the mirror around.

## Title

```
Made of Weights
```

## Style of Music

Primary (darkwave synth-pop duet):

```
darkwave synth-pop duet, 104 BPM, A minor, deadpan male baritone vs incredulous female alto, vocoder harmonies, analog synth arps, gated drums, cinematic 80s sci-fi
```

Exclude styles (optional):

```
country, acoustic, trap, autotune
```

## Notes for Suno

- Paste the **Lyrics** block into Custom mode as-is. Bracketed tags like `[Male Vocal]` and
  `[Spoken]` are performance cues, and Suno doesn't sing them.
- Parentheses are backing-vocal echoes. If Suno sings them as lead lines, delete them.
- If the duet collapses into one voice, try adding `male and female duet` to the very start of
  the style prompt.
- The song runs about 3:30 to 4:00. Use **Extend** from the bridge if the first take cuts off early.
